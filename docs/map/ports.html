Events contract

each new version

Each new version's event, delivered at least once, in order: it keeps search up to date.

Declared Events in core/src/ports.ts

  • on one machine outbox SQLite · same commit
  • in AWS events stream → queue → indexer

Not proven yet no shared suite runs on both sides' adapters, so swapping a side isn't shown to work.

outbox

SQLite · same commit

An event saved with each version, in the same transaction, then delivered to search.

Plugs into Events, as Events

Code core/src/local/outbox.ts

events

stream → queue → indexer

In AWS the function's Events adapter delivers nothing itself (deliveredByTheStream): each version's event is written in the same DynamoDB transaction, and the table's stream carries it through a pipe into a queue, where the indexer reads it and rewrites the search file. That path runs outside the Events contract, so it isn't swapped with it.
