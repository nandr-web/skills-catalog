skills-catalog

MCP server · CLI

One program on each machine: the MCP server Claude Code talks to, and the CLI for a person at a terminal. It sets itself up (skills-catalog setup, undone by teardown), publishes, searches, installs, and keeps installed skills up to date; its rules reviewer flags what a new version adds, and an update that could run something new waits for the person's yes.

catalog on AWS

API · DynamoDB · S3

The shared catalog in the team's AWS account: the API on Lambda behind CloudFront, versions in DynamoDB, files in S3, a search file kept up to date by an indexer. Each version is reviewed as it is published. Only the GitHub logins the deployment lists may sign in.
